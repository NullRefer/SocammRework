## 业务与设备隔离验证

使用仓库外的临时控制台验证器链接实际生产源文件，配合替身 IO/SFC、真实临时 SQLite 和本机 Modbus TCP 模拟端点，共 **43 项检查通过**。没有向仓库新增单元测试项目，没有连接真实 SFC、PLC、螺丝批或生产数据库。

- 上料：SFC 穴位映射、站点与 L/J 配对校验、未知位置、无效 JSON 和缺失 rc 拒绝；要求穴位写入主表。
- 拆螺丝扫码：八穴数组、产品码、更新标记和成功反馈顺序；不存在在线记录时失败。
- 曲线：两套地址关联、仅文件保存、不写 PLC 或主表、无法关联时保留 UNMATCHED 文件；历史文件恢复两把工具的最近曲线。
- 穴位结果：保存后才清零；无在线记录、非法穴位和保存失败不清零；完整要求集合逐穴判定。
- 下料：全要求穴位 OK 才调用 PASS；缺失、NG 或额外穴位不能替代所需结果；处理成功仅软删除主表；SFC 失败保留在线记录；未找到当前产品时不残留上个产品的 OK 展示。
- Runtime 与 IO：真实框架 Runtime 的扫码反馈在清零前；条码控制字符与长度校验；写入最多三次并保留根因；预取消不执行写入。
- Vanguard：真实 Modbus 数据包解析、末块采样、扭矩比例、结果字段、断开与同实例重连、重新配置保留订阅；框架设备目录和 keyed DI 可发现并解析 ITighteningDevice。

- SQLite 初始化脚本重复执行成功，包含 18 张空表；业务只使用 flow 主表，不创建历史表。
- 报表包含软下线记录；曲线文件不替代 PLC 穴位结果。
